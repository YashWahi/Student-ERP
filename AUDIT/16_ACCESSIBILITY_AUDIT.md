# Accessibility Audit — EduERP Pro

## Accessibility & Responsiveness Features
- **Fluid Layout**: Media queries in `globals.css` adapt grid structures across desktop, tablet, and mobile devices.
- **Keyboard Shortcuts**: `CommandSearch.jsx` listens for `Ctrl + K` or `Cmd + K` for global search navigation.
- **Color Contrast**: Modern clean light-mode palette (`var(--color-bg-primary)`, `var(--color-text-primary)`) exceeding WCAG AA standards.
